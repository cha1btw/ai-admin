# Для основателей: что сделать вне кода

У этих пунктов долгие сроки, поэтому их стоит начинать параллельно с разработкой.

- [ ] **Регистрация бизнеса (ФОП).** Без неё не пройти Meta Business Verification, не подписать договор и не принять оплату. Требования Meta к документам: `docs/research/instagram.md`.
- [ ] **Meta:** приложение, Business Verification, потом App Review на доступ к сообщениям. Advanced Access нужен, чтобы обслуживать аккаунты студий, которыми вы не владеете. Вебхуки Instagram приходят, только когда приложение в режиме Live. Для пилота хватит роли тестера у аккаунта студии.
- [ ] **Privacy policy** на вашем домене и страница с инструкцией удаления данных. Черновик: `docs/privacy-notice-uk.md` (показать юристу).
- [ ] **Условия пилота на одну страницу:** что бот делает и чего не делает, 2 недели бесплатно, кто за что отвечает. По персональным данным студия — володілець, вы — розпорядник. Для студий в ЕС понадобится DPA по GDPR.
- [ ] **Метрики пилота заранее:** записи от бота и их сумма, доля обращений вне рабочих часов, время первого ответа, доля передач человеку, ошибки (👎). Попросите студию оценить, сколько вечерних сообщений сейчас остаются без ответа.
- [ ] **Цена после пилота:** считайте от реальной стоимости диалога, её показывает `/stats`.
- [ ] **Кто из вас** ведёт продажи и онбординг, список студий для первых разговоров.

## Как работать с Claude Code в этом репозитории

`CLAUDE.md` читается в каждой сессии: там правила R1–R13, архитектура и фазы. Поведение продукта и сценарии описаны в `docs/PRODUCT.md`. Просите изменения по одной фазе или задаче за раз и проверяйте отчёт: что запускалось, что нет.
